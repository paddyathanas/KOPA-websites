# KOPA · Ιστοσελίδες για κάθε επιχείρηση

Η ιστοσελίδα της KOPA: σχεδιασμός ιστοσελίδων και e-shop, σε Αθήνα και σε όλη την Ελλάδα.

## Αρχεία

```
index.html     όλη η ιστοσελίδα (κείμενα, εμφάνιση, λειτουργίες)
images/        οι φωτογραφίες, τα στιγμιότυπα των έργων και το λογότυπο KOPA
.nojekyll      για σωστή λειτουργία στο GitHub Pages
```

Η σελίδα έχει τις ενότητες **Αρχική**, **Έργα**, **Διαδικασία**, **Επικοινωνία** και **Ζητήστε Προσφορά**. Όλες βρίσκονται μέσα στο `index.html` και αλλάζουν με το `#` στο τέλος του link (π.χ. `#erga`, `#prosfora`).

## Συχνές αλλαγές

Ανοίξτε το `index.html` και αναζητήστε (Ctrl+F):

| Τι θέλετε να αλλάξετε | Αναζητήστε |
|---|---|
| Τηλέφωνο, email, ωράριο, διεύθυνση | `var CONFIG` |
| Τα έργα του portfolio (προσθήκη/αφαίρεση) | `var PROJECTS` |
| Κλειδί για αποστολή της φόρμας στο email | `formKey` |

Για νέο έργο, αντιγράψτε ένα από τα `{ id: ... }` μέσα στο `PROJECTS` και αλλάξτε όνομα, περιγραφή, link και εικόνες (βάλτε τις εικόνες στον φάκελο `images/`).

## Ανέβασμα online (GitHub Pages)

1. Στο GitHub: **Settings → Pages**.
2. Στο **Source** επιλέξτε **Deploy from a branch**, branch **main**, φάκελο **/ (root)** και πατήστε **Save**.
3. Σε 1–2 λεπτά η σελίδα θα είναι διαθέσιμη στο `https://paddyathanas.github.io/KOPA-websites/`.
4. Για δικό σας domain (π.χ. `kopa-websites.com`), συμπληρώστε το στο **Custom domain** της ίδιας σελίδας και ρυθμίστε τα DNS όπως δείχνει το GitHub.

## Αποστολή της φόρμας στο email

Η φόρμα «Ζητήστε Προσφορά» είναι έτοιμη να στέλνει τα αιτήματα στο email σας μέσω της δωρεάν υπηρεσίας Web3Forms:

1. Μπείτε στο [web3forms.com](https://web3forms.com), γράψτε το `info@kopa-websites.com` και θα λάβετε ένα **Access Key**.
2. Στο `index.html` βάλτε το κλειδί στο `formKey: ""` (μέσα στα εισαγωγικά).
3. Ανεβάστε την αλλαγή. Από εκεί και πέρα κάθε αίτημα θα έρχεται αυτόματα στο email σας.

Η φόρμα έχει ήδη προστασία από spam: έλεγχο «Δεν είμαι ρομπότ» με ερώτηση πρόσθεσης, κρυφό πεδίο που πιάνει τα ρομπότ και έλεγχο χρόνου συμπλήρωσης.
